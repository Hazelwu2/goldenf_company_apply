# 產品商下拉選單規格

> **本文件是產品商下拉選單規則的唯一來源。**
> 其他文件（[開線申請 API 規格](開線申請_API_規格.md)）只描述 API 格式，規則一律連到這裡。
> 修改規則時，請同一次變更一起更新本文件、程式與測試（對照見第 7 節）。

最後更新：2026-09-30

## 1. 用途

客戶在「營運商 A」頁選擇要申請開通的產品商（可多選）。送出開線申請時，選到的產品商代碼放進 A record 的 `vendors`。

產品商必須先選幣別才能選，因為產品商是否可選取決於它支不支援該幣別。

## 2. 資料來源

```http
GET /api/v1/company_apply/vendor/list
```

後端回傳所有產品商的精簡資料，**由前端決定哪些產品商顯示、放在哪一組**。外層 envelope 規則與其他 API 相同（`status` 為 `1` 才是成功）。

### 2.1 回應範例

```json
{
  "status": 1,
  "message": "成功",
  "data": {
    "totalCount": 1,
    "currentPage": 0,
    "perPage": 0,
    "list": [
      {
        "code": "betby",
        "name": "BETBY 體育／BETBY",
        "status": "online",
        "status_v3": "decommission",
        "demo": true,
        "support": { "v2": true, "v3": false },
        "currency": {
          "VND": { "vendor": "VND", "rate": "1", "gf_support": false, "decimal": "" }
        }
      }
    ]
  }
}
```

### 2.2 前端使用的欄位

| 欄位 | 型別 | 前端用途 |
|---|---|---|
| `code` | string | 送出時放進 `vendors` 的值；畫面不顯示，但可以用來搜尋 |
| `name` | string | 選項與已選標籤的顯示名稱，原樣顯示（可能同時含中英文） |
| `status` | string | 只有 `online` 可以出現在選單 |
| `demo` | boolean | 是否提供測試環境（可試玩），決定放在哪一組 |
| `support.v2` | boolean | 必須為 `true` 才能出現在選單 |
| `currency` | object | **以幣別代碼為 key 的物件**（不是陣列），value 的 `vendor` 為非空字串才代表原廠支援該幣別 |

以下欄位前端**不使用**：`status_v3`、`support.v3`、`currency.*.rate`、`currency.*.gf_support`、`currency.*.decimal`、`totalCount`、`currentPage`、`perPage`。

### 2.3 格式檢查

- 任何一筆產品商缺少 `code`、`name`、`status`（字串）、`demo`（boolean）、`support`（物件）、`currency`（物件）→ 整份清單視為格式錯誤，畫面顯示「载入失败」並可重試。
- `support.v2` 或 `currency` 裡某個幣別的 `vendor` 型別不對 → 只有這間產品商不出現在選單，其他照常。

## 3. 顯示規則

依序判斷：

### 3.1 完全不出現

符合任一條件的產品商不會出現在選單：

- `status !== "online"`
- `support.v2 !== true`
- `currency` 裡沒有任何一個幣別的 `vendor` 是非空字串

### 3.2 先看幣別，再看測試環境

剩下的產品商依「使用者選的幣別」分成三組：

| 條件 | 分組 | 可否選取 | 標籤 |
|---|---|---|---|
| 支援所選幣別，且 `demo === true` | 正式与测试环境 / Production & Test | 可選 | 綠色「正式＋测试 / Prod. + Test」 |
| 支援所選幣別，且 `demo === false` | 仅正式环境 / Production Only | **可選** | 灰色「仅正式 / Production」 |
| 不支援所選幣別 | 不支持 XXX / Unavailable for XXX（排最後） | 停用 | 橘色「不支持 XXX / Unavailable」 |

- 「支援所選幣別」：`currency[所選幣別].vendor` 為非空字串。
- 各組內維持後端回傳的順序；沒有產品商的分組不顯示。
- 沒有測試環境（`demo === false`）的產品商**可以申請**，後端建立申請時不會擋。

### 3.3 Motivation

Motivation 以獨立產品商出現，規則與其他產品商相同。選到時照原始 code 送出，前端不轉成 CQ9（內部人員開線時自行處理）。

## 4. 欄位狀態

| 情況 | 產品商欄位 | 提示 |
|---|---|---|
| 尚未選幣別 | 停用，placeholder「请先选择币别 / Select currency first」 | 「请先选择币别后再选择产品商。」 |
| 清單載入中 | 停用，placeholder「正在载入产品商 / Loading vendors」 | 「正在载入可用产品商。」 |
| 清單載入失敗 | 停用，placeholder「产品商载入失败 / Failed to load vendors」 | 錯誤訊息＋「重新载入 / Retry」按鈕 |
| 清單為空（沒有可選的產品商） | 停用，placeholder「暂无可用产品商 / No vendors available」 | 「目前没有可用产品商，请稍后再试。」 |
| 可以選 | 可多選、可搜尋（比對名稱與代碼） | 「支持 XXX 的产品商优先显示；不支持的项目列于最下方。」 |

產品商清單在同一次使用中只載入一次，營運商 A 頁、確認頁、換幣別確認框共用同一份資料。

## 5. 互動規則

### 5.1 換幣別

已選產品商中有不支援新幣別的，先跳確認框，列出「将取消勾选」與「继续保留」的產品商：

- 確認：切換幣別，並移除不支援新幣別的產品商。
- 取消：維持原幣別與原選取。
- 已選產品商全部支援新幣別時，直接切換，不跳確認框。

### 5.2 已選產品商失效

已選的產品商符合以下任一情況即為**失效**（例如草稿存了一段時間後，產品商下線了）：

- 不在可選清單中（已消失、下線、不支援 2.0、沒有原廠幣別）
- 不支援目前選的幣別

失效時：

- 已選標籤顯示為紅色「名稱（已失效）」，可以點 × 移除。
- 欄位下方顯示「请移除失效的产品商：A、B / Remove unavailable vendors: A, B」。
- 還有失效項目時不能前往下一步；按下一步會聚焦到產品商欄位。

幣別不可用、或產品商清單載入中／失敗／為空時不判斷失效（由對應的提示處理），且不能前往下一步。

### 5.3 送出後後端回報產品商錯誤

建立申請時後端以 `field: "vendors"` 回報錯誤，前端會標記產品商清單需要重新載入，下次進入營運商 A 頁時重新取得。（重新載入機制已完成；送出失敗時呼叫它，隨「送出失敗處理」一起完成）

## 6. 送出

- A record 的 `vendors`：已選產品商的 `code` 陣列，至少一個。
- 在確認頁按「確認送出」時會再檢查一次：產品商清單必須已載入且不為空、所選幣別仍可用、不得有失效的產品商；不符合時不送出，導回營運商 A 頁並聚焦產品商（或幣別）欄位。
